CONTENT PUBLISHING WORKFLOW

How to publish an update.

Content is stored in JSON arrays under content/.

  1. Open the editorial workspace and create a draft.
  2. Download its JSON file.
  3. Send the downloaded JSON file to Mira. (You do not need to edit the website files or GitHub yourself.)
  4. Mira adds the record to the matching file in content/ — articles.json, news.json or stories.json — and checks that the commas and quotation marks keep the JSON valid.
  5. The record's status is changed from draft to published only after editorial review.
  6. Mira deploys the updated site to Cloudflare Pages — that upload is what makes the update live — and mirrors the same code to the GitHub repository. This site is not connected to GitHub for automatic deployment, so a GitHub commit on its own does not change the live website.

Access control

The admin page is a local draft helper, not secure authentication or a publishing server. Anyone who opens it can create a local draft, but a draft on its own changes nothing on the website. Publishing happens only when Mira adds the reviewed record to the site files and deploys the update, using the site owner's access.

Editorial checklist

  • Check names, spellings, dates, locations and citations.
  • Get permission for photos, recordings and personal stories.
  • Ask native speakers to review language resources.
  • Respect restricted cultural knowledge.
  • Label uncertainty honestly.

Adding images, videos and embeds

Images. Only use photographs that are public domain or Creative Commons licensed (CC0, CC BY, CC BY-SA) — Wikimedia Commons first, then Openverse, Unsplash or Pexels. Never take images from blogs, news sites, Instagram, Pinterest or Google Images, and never hotlink: download the file, save it in assets/img/ (max width about 1200px), and always fill in the caption, credit, source page and licence fields. A photo may only be used where it genuinely shows that subject. Every photo must also be listed in the About page’s “Photo & media credits” section.

Videos & posts. In the editor, add a media item and paste the full URL: a YouTube watch link becomes YouTube’s official privacy-enhanced embed; an Instagram post or Reel link becomes the official Instagram embed; an X post link becomes the official X embed; a Facebook post or video link becomes the official Facebook plugin. Each embed shows a fallback link underneath. Nothing is ever downloaded from social media. Share buttons (WhatsApp, Facebook, X, Telegram) are added automatically on every article, news and story page.

Publishing stays owner-only. This helper only creates a draft. Send the exported JSON to Mira; Mira reviews it, adds it to the site files, deploys the update to Cloudflare Pages (mundarisamaj.pages.dev) and mirrors the same code to the GitHub repository (catversstudio/mundari-samaj). This site is not connected to GitHub for automatic deployment.
