The admin panel does not run here

This copy is only a preview. The live admin panel runs on the main website — mundarisamaj.pages.dev/admin — once the new version is deployed there. Sign in there to manage all content from your phone.

First-time setup — create your password

This happens only once. Enter the one-time setup code you received, your email and a new password. Your password is stored only in hashed form in the database — nobody can read it.

Admin sign in

Sign in with your email and password. Your session is remembered for 7 days.

Reset password — with a recovery code

Enter your recovery code (the one you created in the Security section of this panel and kept somewhere safe), your email and a new password. A recovery code works only once — after a reset you will need to create a new one.

Edit word

Download backup

All content and the dictionary in a single JSON file. Keep this file safe — it is your backup.

Restore a backup

Choose an earlier backup file. Existing items are updated, new items are added. Nothing is deleted.

Security — change password

Changing your password signs out every other device — only this device stays signed in.

Sign out everywhere

If your account may still be open somewhere else, sign out on every device with one click. You will need to sign in again here too.

Recovery code — if you forget your password

Create one secret code and keep it somewhere safe (a notebook or a password manager). If you ever forget your password, use “Forgot your password?” on the sign-in page with this code to set a new one yourself — no help needed. A code works only once; creating a new one cancels the old one.

Checking recovery code status…

Click any block to edit it right there — exactly as readers see it. Use the small buttons on a block to move it up or down, or delete it.
