PRIVATE EDITORIAL WORKFLOW

Create a content draft.

This helper creates a JSON draft file for the website's content folder. It does not publish directly.

Security: This page is a local draft helper, not a login or security system. Anyone who opens it can create a draft, but a draft changes nothing on the website — publishing happens only when Mira adds it to the site files and deploys the update, using the site owner's access. Never place a password or token in this website.

New content

Featured image

Use only public-domain / CC-licensed images (Wikimedia Commons first). Save the file into assets/img/ and write its path, e.g. assets/img/sarhul.jpg. Credits are mandatory.

Media items (videos & embeds)

Add a row per video or post. Paste the full YouTube / Instagram / X / Facebook URL — the website turns it into the official embed automatically. Nothing is downloaded from social media.

How publishing works

  1. Download the JSON draft from this page.
  2. Send the downloaded file to Mira.
  3. Mira adds the record to the matching file in content/ and reviews it.
  4. The record's "status" is changed from "draft" to "published" only after that review.
  5. Mira deploys the updated site to Cloudflare Pages — that is what makes it live — and mirrors the same code to the GitHub repository. (This site is not connected to GitHub for automatic deployment.)
